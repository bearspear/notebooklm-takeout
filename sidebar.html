Note Options

Applies to notes and to the chat export (the Chat tab and Export everything). "Source titles only" skips reading each citation's popup: every [n] still links to its source (one line per source), without the quoted passage. "No citations" removes the [n] markers and the Sources section for clean text. Both are much faster for large exports.

Links writes each [n] as a link to its source, with the quote in the Sources section (works in any viewer). Footnotes writes [^n] markers with a footnote definition per source, which Obsidian, Typora and other Markdown apps show as real footnotes. Applies to notes and chat with "Full quotes" or "Source titles only"; the "code blocks" version keeps links. In combined files the footnotes are numbered per note (1-1, 2-1, …). Opt-in: please check how your Markdown app shows them.

Removes characters that break Obsidian links ([ ] # ^ | \ : * ? " < >) from note, source and artifact file names, and names single downloads "note - Title" and "mind-map - Title" instead of "[NOTE]_Title". Off by default; the usual file names are unchanged.

When a note or chat answer has not changed since an earlier full-quote export, its citation quotes are read from a local cache instead of hovering every marker again. Not used when an "images" version is exported. If a source was edited, clear the cache.
