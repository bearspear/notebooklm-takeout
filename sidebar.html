Number of sources to include in each ZIP file. Lower values use less memory and are safer for large exports. Higher values create fewer ZIP files. Recommended: 25 for most users, 10-15 for low-memory systems, 50+ for powerful systems.

Note Options

Links writes each [n] as a link to its source, with the quote in the Sources section (works in any viewer). Footnotes writes [^n] markers with a footnote definition per source, which Obsidian, Typora and other Markdown apps show as real footnotes. Applies to notes and chat with "Full quotes" or "Source titles only"; the "code blocks" version keeps links. In combined files the footnotes are numbered per note (1-1, 2-1, …). Opt-in: please check how your Markdown app shows them.

When a note or chat answer has not changed since an earlier full-quote export, its citation quotes are read from a local cache instead of hovering every marker again. Not used when an "images" version is exported, which includes every note and chat export under Archive; AI-ready or Custom without Image copies uses it. If a source was edited, clear the cache.
