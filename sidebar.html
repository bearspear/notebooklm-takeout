General

Adds a fifth tab that mirrors NotebookLM's studio panel as a single flat list (notes, mindmaps, audio, slides, infographics, reports, data tables, flowcharts). Each row can be downloaded or deleted individually — no ZIP. Off by default.

Export Format

Source Options

Choose which combinations of source files to export. At least one version must be selected.

Number of sources to include in each ZIP file. Lower values use less memory and are safer for large exports. Higher values create fewer ZIP files. Recommended: 25 for most users, 10-15 for low-memory systems, 50+ for powerful systems.
